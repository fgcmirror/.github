# fgcmirror — org-level config & landing page

This repository holds shared configuration for the [fgcmirror](https://github.com/fgcmirror) GitHub organization, and the source of the landing page at <https://fgcmirror.com>.

- `profile/README.md` — the org's public profile page (rendered on <https://github.com/fgcmirror>).
- `docs/` — source of <https://fgcmirror.com> (GitHub Pages).

## What is fgcmirror?

A community effort to preserve historic websites from the fighting-game community before they disappear. Each preserved site becomes a public repository under this organization, served at `<slug>.fgcmirror.com` via GitHub Pages.

## Request a site

Open an issue here describing the site (URL + Wayback link if it's dead). We'll capture and publish it.

## Contribute to an existing mirror

Each per-game repo's `README.md` lists assets that couldn't be recovered. PRs welcome.
