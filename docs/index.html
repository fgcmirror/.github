02 · About

The project

// what we preserve

FGC Mirror preserves the official websites of fighting games — the character bios, move lists, art galleries and intros that the genre grew up on — so they keep working long after the original servers go dark.

Most of these sites are built on technology the modern web has left behind. We rebuild each one from the ground up so opening a mirror today feels exactly like opening the original page did.

That includes the Flash. Original animations, intros and character viewers are kept and made playable again in any browser, with no plugin. Every image, sound, font and embedded file is pulled into the repository and served alongside the page — so the mirror is fully self-contained, works offline, and outlives any single host.
