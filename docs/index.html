fgcmirror

Preserving historic websites from the fighting-game community before they disappear.

Many of the sites that documented fighting games — character pages, move lists, official sites, fan portals — are dead or one server migration away from being lost. fgcmirror archives them as static, fully self-contained mirrors served from github.com/fgcmirror.

Each mirror lives at its own subdomain (<slug>.fgcmirror.com) and is its own public repository. Anyone can browse the source, propose fixes, or backfill missing assets via pull request.

How to help

Know a site that should be preserved?
Open an issue at github.com/fgcmirror/.github with the URL (and a Wayback link if the site is dead). We'll capture and publish it.

Found a missing asset or a better snapshot for an existing mirror?
Open a PR on the corresponding repo. Each repo's README.md lists what's missing.
